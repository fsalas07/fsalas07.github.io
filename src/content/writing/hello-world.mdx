This site is meant to read like a typeset paper and load like a text file. Everything below is a design decision I can defend, or at least explain.

## Type

The body face is Newsreader, set at about twenty pixels on a desktop screen with a measure near sixty-five characters.<Sidenote>Newsreader is a variable font, so one file covers every weight. Code is set in JetBrains Mono. Both are self-hosted; the page makes no third-party requests.</Sidenote> Running text uses old-style numerals, such as 1984 or 2026, which sit at the height of lowercase letters. Tables switch to lining, tabular figures so that columns align.

| Element        | Face           | Numerals           |
| -------------- | -------------- | ------------------ |
| Body text      | Newsreader     | old-style          |
| Tables, dates  | Newsreader     | lining, tabular    |
| Code           | JetBrains Mono | n/a                |

Headings are restrained: second-level headings are italic and third-level headings are small capitals.<MarginNote>This is the same hierarchy Tufte's books use, minus the red.</MarginNote> The only colour is a dark red used for links on hover, focus rings and note numbers.

> Above all else show the data.
>
> <cite>Edward Tufte</cite>

## Layout

On a wide screen the page has a text column and a margin. Notes live in the margin, next to the sentence they annotate, instead of at the bottom of the page where they are easy to ignore. On a narrow screen there is no margin, so each note collapses behind its number and expands in place when you tap it.<Sidenote>The toggle is a hidden checkbox and a label, so it works without JavaScript and can be operated from the keyboard.</Sidenote>

The technique is borrowed from Tufte CSS.[^1] Ordinary Markdown footnotes still work and appear at the end of the article.

## Mathematics

Maths is rendered with KaTeX when the site is built, so no script runs in the browser. Inline, the identity $e^{i\pi} + 1 = 0$ is as pretty as ever. Displayed, the Gaussian integral looks like this:

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

The stylesheet for it is only loaded on posts that declare `math: true` in their front matter.

## Code

Code blocks are highlighted at build time as well, with a light and a dark theme that follow the site's theme toggle. The colour tokens are defined once and flip with `light-dark()`:

```css
:root {
  color-scheme: light dark;
  --bg: light-dark(#fffff8, #171614);
  --ink: light-dark(#1a1a1a, #e8e6e1);
}

:root[data-theme='dark'] { color-scheme: dark; }
```

## What ships

There is no framework runtime on ordinary pages. The only scripts are a few lines that set and toggle the theme, plus Astro's link prefetching. Interactive demos, when they appear, will be isolated islands that only load where a post asks for them.

[^1]: Dave Liepmann's [Tufte CSS](https://edwardtufte.github.io/tufte-css/) is the reference implementation of sidenotes in plain CSS.
