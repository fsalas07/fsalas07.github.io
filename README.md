# fsalas07.github.io

Personal site and writing. Built with Astro, deployed to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```

- Pages: `src/pages/` (home, projects, cv, now)
- Posts: `src/content/writing/*.mdx`
- Interactive demos: `src/components/demos/`
- Press `?` on the site for keyboard shortcuts.
